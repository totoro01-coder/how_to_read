# 독서 카드게임

방 앞에서 방문을 통해 들어가 방 안에서 책을 읽는 경험을 1인용 카드게임으로 옮긴 웹 게임이에요.

## 구조

```
index.html        게임 전체 (규칙, 화면, 모션)
cards/            카드 그림 SVG
```

## 카드 그림 바꾸기

`cards/` 폴더에 아래 이름으로 SVG를 올리면 자동으로 적용돼요. 코드는 고치지 않아도 돼요.
같은 이름으로 덮어쓰면 그림이 바뀌고, 파일이 없는 카드는 임시 그림으로 보여요.

| 카드 | 파일 이름 |
|---|---|
| 자리 10장 | `seat-01.svg` ~ `seat-10.svg` |
| 방해 4종 | `dist-01.svg` ~ `dist-04.svg` |
| 무마 5종 | `ctr-01.svg` ~ `ctr-05.svg` |
| 페이지 (30장 공통) | `page.svg` |
| 책 7종 | `book-01.svg` ~ `book-07.svg` |
| 메인 덱 뒷면 | `back-main.svg` |
| 책 카드 뒷면 | `back-book.svg` |

- 규격: SVG, 아트보드 630 × 880 (63 × 88 mm)
- 글자는 윤곽선(Create Outlines)으로 바꾸고, 외부 이미지 링크는 넣지 않기
- 이름은 영문 소문자와 숫자, 하이픈만 쓰기 (대소문자 구분됨)
- 카드 이름과 숫자는 게임이 그림 위에 올려요

## 올린 뒤 그림이 안 바뀌어 보일 때

GitHub Pages는 파일을 몇 분 동안 저장해 둬요. `Ctrl/Cmd + Shift + R`로 강력 새로고침해 보세요.
